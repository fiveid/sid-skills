# Proposals

Possible ways forward, and areas for further research, based on the experience in [HUMANS.md](../../HUMANS.md). These are less proven than the [guides](../guides/README.md): frameworks I find useful but haven't fully tested, or decisions a team still needs to make.

Each proposal opens with a **Status** line saying how far it has been tried, and a **Responds to** line naming the risk it addresses. Once a proposal has been tried and holds up, it can graduate: the practical parts become a guide, and the principle moves into HUMANS.md.

| Proposal | What it covers |
| :--- | :--- |
| [Project lifecycle](project-lifecycle.md) | Three phases (discovery, buildout, production) with example checkpoints between them. |
| [Hierarchy of verification](hierarchy-of-verification.md) | Five levels of review responsibility, from CI up to intent. |
| [Sandboxing](sandboxing.md) | Three tiers of agent isolation, and their trade-offs. |
